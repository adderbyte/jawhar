جوهرة الصحراء — دليل إدارة المحتوى

أولًا: فكرة العمل
كل عنصر (مقالة، كتاب، مجلة، برنامج، باحث، عضو فريق) له مجلد خاص داخل content/ يضم صورته وملف info.txt (نصه) وملف PDF عند الحاجة. تُقرأ هذه المجلدات ويُبنى منها الموقع تلقائيًا في مجلد public/.

ثانيًا: هيكل المجلدات (أسماء عربية بحروف لاتينية)
content/
  site/                          الشعار والبانر الرئيسي وبيانات الاتصال
  maqalat/<التاريخ>-<الاسم>/      المقالات: image.jpg  info.txt  text.txt  (maqala.pdf)
  isdarat/kutub/<الاسم>/          الكتب: cover.jpg  info.txt  kitab.pdf
  isdarat/majallat/<الاسم>/       المجلات: cover.jpg  info.txt  adad.pdf
  baramij/<رقم-الاسم>/            البرامج: image.jpg  info.txt
  ashkhas/kuttab-wa-bahithun/<رقم-الاسم>/   كتابنا وباحثونا: photo.jpg  info.txt
  ashkhas/fariq-al-amal/<رقم-الاسم>/        فريق العمل: photo.jpg  info.txt
  _namadhij/                     نماذج جاهزة للنسخ (لا تظهر في الموقع)

ثالثًا: الإضافة والتعديل والحذف
- إضافة عنصر: انسخ مجلد نموذج من _namadhij/ (أو أي عنصر موجود) إلى القسم المناسب، وغيّر اسم المجلد (حروف لاتينية صغيرة وشرطات، بلا مسافات)، واملأ info.txt، وضع الصورة بالاسم المحدد.
- تغيير صورة: استبدل الملف بصورة جديدة تحمل الاسم نفسه تمامًا.
- حذف عنصر: احذف مجلده كاملًا (الصورة والنص والملفات معًا).
- ترتيب العناصر: المقالات تُرتَّب حسب date في info.txt (الأحدث أولًا). الكتب والمجلات حسب year. البرامج والباحثون والفريق حسب الرقم في بداية اسم المجلد (01- ثم 02- ...).

رابعًا: ملف info.txt
كل سطر بصيغة  المفتاح: القيمة  (المفاتيح بالإنجليزية والقيم بالعربية). الأسطر التي تبدأ بـ # تعليقات.
- مقالة:  title, author, date (بصيغة 2026-10-17), topic, summary
- كتاب أو مجلة:  title, author, year, latest (yes ليظهر في «آخر الإصدارات» وإلا no), summary, description
- برنامج:  title, description
- باحث:  name, role, bio, ثم works: وتحته أسطر تبدأ بـ -  لكل مؤلَّف أو مشاركة
- عضو فريق:  name, position
- site/info.txt:  email, whatsapp (أرقام فقط مع رمز الدولة), phone

خامسًا: مقاسات الصور (بالبكسل)
- البانر الرئيسي banner.jpg: 1920×640
- الشعار logo.jpg: 400×400
- صورة المقالة image.jpg: 1280×720 (تُقصّ تلقائيًا في القوائم، فاجعل الموضوع في الوسط)
- غلاف كتاب أو مجلة cover.jpg: 900×1200 (الحد الأدنى 600×800)
- صورة برنامج image.jpg: 1200×600
- صورة باحث أو عضو photo.jpg: 400×400
الصيغة المفضلة JPG، والحجم الأفضل أقل من 150 كيلوبايت للصورة (200 للبانر).

سادسًا: بناء الموقع
بعد أي تغيير شغّل:  python build.py
ينتج مجلد public/ ويحتوي index.html والصور وملفات PDF فقط. أما build.py وtemplate.html وملفات info.txt وtext.txt فلا تُنشر.
لمعاينة الموقع محليًا: افتح public/index.html (أو شغّل خادمًا محليًا داخل مجلد public).
زر «دليل الاستبدال» في الصفحة يُظهر لكل صورة اسم الملف المطلوب ومكانه.

سابعًا: النشر على Vercel (ربط عبر Git)
في إعدادات المشروع:
- Framework Preset: Other
- Build Command: python3 build.py
- Output Directory: public
بعد ذلك يكفي أن تدفع (push) تغييراتك إلى Git ليُعاد البناء والنشر تلقائيًا.
يُنصح بإضافة سطر  public/  إلى ملف .gitignore، لأن مجلد public يُولَّد عند كل بناء.

ملاحظات
- ملفات PDF للكتب والمجلات: ضع ملف PDF داخل مجلد العنصر (أي اسم ينتهي بـ .pdf) فيرتبط تلقائيًا بزرّي «قراءة» و«تحميل».
- بطاقات المقالات والبرامج لا تفتح صفحات مستقلة بعد؛ هذه خطوة لاحقة.
